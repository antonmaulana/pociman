# Pociman: The Village Chase

Game web 2D kocak bertema kejar-kejaran pocong dan warga kampung di malam hari. Dibangun murni menggunakan **HTML5 Canvas** dan **Web Audio API** tanpa dependency eksternal.

## 🎮 Kontrol Game
- **HP & Tablet (Sentuh Layar):** Tap 1x untuk Lompat, Tap 2x untuk Double Jump di udara.
- **Mouse / Laptop (Klik):** Klik Kiri 1x untuk Lompat, Klik 2x untuk Double Jump.
- **Keyboard (Tombol):** `[SPASI]`, `[↑]`, atau `[W]` untuk Lompat. `[P]` untuk Pause/Jeda.
